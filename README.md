# DiziTech 1.4

Компактный двуязычный лендинг студии разработки сайтов. Четыре зоны: hero, услуги, этапы и объединённые контакты/стоимость/подвал. Почти чёрная типографика на светлом фоне; белая на navy. В шапке только существующий логотип, ҚАЗ / РУС и WhatsApp. Сохранены синие акценты и шесть SVG-сюжетов услуг. HTML, CSS, JavaScript ES Modules и Canvas 2D; без backend и runtime-зависимостей.

В 1.4 выполнены только две правки: упрощена шапка и обновлены цвета текста. Высота страницы и размеры шрифтов точно совпадают с 1.3 на всех восьми проверенных ширинах и двух языках. Версии 1.0–1.3 сохранены отдельно; другие проекты не изменялись. Подробности: [изменения](CHANGELOG.md), [проверки](TESTING.md), [сравнение 1.3 → 1.4](reports/comparison/index.html).

На desktop элементы шапки стоят в одну строку. На телефоне логотип и языки расположены сверху, полная WhatsApp-кнопка — ниже на всю ширину; её надпись помещается даже на 320 px без сокращения и уменьшения шрифта. Высота шапки сохранена. Старые ссылки, hamburger, обработчики меню, breakpoint-логика и наблюдатель активного пункта удалены. Меню не создаётся и без JavaScript.

## Запуск

Требуется Node.js 22+; проверено на Node.js 24 и установленном Google Chrome.

```powershell
Set-Location C:\Users\User\DiziTech
npm.cmd ci
npm.cmd run dev
```

Открыть **http://127.0.0.1:4173/**; русский маршрут — **http://127.0.0.1:4173/ru/**. Если сервер уже запущен, обновите страницу. Dev пересобирает файлы при изменениях; browser refresh выполняется вручную. Остановка — `Ctrl+C`.

```powershell
npm.cmd run build          # Статическая локальная сборка dist/
npm.cmd run preview        # HTTP-сервер готовой dist/ на 4173
npm.cmd run build:release  # Публичный режим; требует реальных настроек
npm.cmd run build:pages    # Готовый production-сайт в docs/ для main /docs
npm.cmd test               # Playwright + axe + проверка шрифта
npm.cmd run audit          # Lighthouse; нужен сервер на 4173
```

На macOS/Linux используйте `npm` вместо `npm.cmd`. Для сервера доступна переменная `PORT`. ES Modules требуют HTTP-сервера: прямой запуск через `file://` не поддерживается.

## Контакты — только site.config.mjs

| Поле | Назначение |
| --- | --- |
| `whatsapp` | Реальный международный номер, 7–15 цифр, без `+` и пробелов |
| `phone` | Реальный телефон; допустимы `+`, пробелы, скобки |
| `email` | Реальная электронная почта |
| `siteUrl` | Реальный полный HTTPS-адрес сайта с завершающим `/` |
| `githubAccount` | Подтверждённый владелец репозитория |
| `githubRepository` | Подтверждённое название репозитория |

WhatsApp, телефон и email пока пусты и остаются необязательными при публикации. Подтверждённые параметры хостинга: `https://dizzitech.github.io/`, аккаунт `dizzitech`, репозиторий `dizzitech.github.io`. Для отсутствующих контактов нет неработающих ссылок; показано «Контакты скоро появятся» и казахский перевод. Четвёртое поле отображает реальный адрес сайта.

После заполнения и пересборки все кнопки заказа автоматически открывают `https://wa.me/НОМЕР?text=…` с сообщением на текущем языке, телефон получает `tel:`, почта — `mailto:`, адрес сайта — HTTPS-ссылку. Компоненты менять не нужно. Второго конфигурационного файла нет: `dist/site.config.js` генерируется сборщиком из основного файла и содержит только публичные данные.

Подписи различаются: hero — **«Тапсырыс беру» / «Заказать сайт»**, шапка — **«WhatsApp-қа жазу» / «Написать в WhatsApp»**, нижняя зона — **«WhatsApp арқылы байланысу» / «Связаться через WhatsApp»**. Без номера в preview открывается доступный информационный диалог; без JavaScript кнопка ведёт к состоянию контактов.

`build:release` и `build:pages` требуют только заполненные параметры хостинга (`siteUrl`, `githubAccount`, `githubRepository`). Отсутствующие контакты не блокируют production-сборку. Указанные контакты по-прежнему проходят проверку формата; стандартный Pages URL должен соответствовать аккаунту и репозиторию. Секреты, пароли и токены в эту публичную конфигурацию не помещать.

## Шрифт и оформление

Сохранён **Golos Text Variable** (обычные начертания 400–700). Локально поставляются Latin, Cyrillic и Cyrillic Extended; внешних CDN нет. SIL OFL: `dist/assets/fonts/OFL.txt`. Chrome повторно проверил фактическую отрисовку национальных казахских букв, русского алфавита и латиницы этим шрифтом — [`reports/font-coverage.json`](reports/font-coverage.json).

Цвета определены CSS-переменными в `src/css/styles.css`: основной текст `--text: #111111`, заголовки `#0B0F19`, вторичный текст `#242424`, дополнительные подписи `#333333`, ссылки `#155EEF`. Весь белый текст на navy и надписи primary-кнопок — чистый `#FFFFFF`, включая описания, подписи, контакты и footer. Синий hover `#1048C5`, фон `#F8FAFF`, границы `#D8E2F0` и графические акценты сохранены. Прежняя `--ink: #101828` оставлена только для неизменной палитры Canvas и его HTML-fallback; обычная типографика её не наследует. Глобальных фильтров и смешивания нет. Актуальная проверка чистого белого, opacity предков, hover/focus и неизменности чёрного текста: [`reports/white-text-after.json`](reports/white-text-after.json).

Обычный текст 17–18 px, описания услуг 16–17 px, основные кнопки 17–19 px. В шапке и компактных служебных подписях используются отдельные размеры. Проверяемые размеры текста точно совпадают с 1.3. SVG встроены в HTML и не требуют сетевых запросов: одностраничный сайт, компания, учебный портал, материалы, сравнение интерфейсов и стабильность. Карточки сохраняют сетку 3/2/1 и прежний hover с отключением движения при reduced motion.

Код сети и курсора побайтово совпадает с 1.3, цвета Canvas сохранены. В `app.js` удалена только ставшая ненужной логика меню и подсветки навигации. Mouse-drag с pointer capture, инерция, авто, hover, центральный DiziTech, анимации, пауза, touch-scroll и reduced motion сохранены. Разметка основных секций, SVG-определения и логотип тоже совпадают с 1.3. Контрольные суммы и проверки: [`reports/preservation.json`](reports/preservation.json).

## Содержание и структура

```text
site.config.mjs       Единственный исходный конфиг контактов и хостинга
src/template.html     Четыре смысловые зоны и доступный диалог
src/css/styles.css    Типографика 1.4 и сохранённая дизайн-система
src/i18n/             Полные словари kk / ru
src/js/app.js         Язык, диалог, reveals и состояние шапки
src/js/network.js     Сохранённая интерактивная сеть
src/js/cursor.js      Курсор с контрастным состоянием на navy
public/assets/        Favicon и актуальный Open Graph
scripts/              Сборка, сервер, Lighthouse, изображения, сравнение
tests/                Браузерные тесты и контрольные замеры 1.1–1.3
reports/              Фактические отчёты, снимки и сравнение
dist/                 Собранные статические файлы
docs/                 Готовый production-сайт; источник GitHub Pages main /docs
```

Казахский — основной язык первого посещения. Выбор сохраняется, если доступен localStorage. `/` и `/ru/` содержат полноценный HTML; JS переключает язык без reload с обновлением URL, `lang`, aria, SEO-текстов и сообщения WhatsApp. При недоступном JavaScript сохраняются контент, навигация, отдельные языковые страницы и состояние контактов.

Нет вымышленных цен, отзывов, клиентов или портфолио. Стоимость описана в финальной зоне как индивидуальный расчёт. Услуги прямо перечисляют типы сайтов, образовательные организации и содержание поддержки.

## GitHub Pages из main /docs

Репозиторий: [dizzitech/dizzitech.github.io](https://github.com/dizzitech/dizzitech.github.io). Сайт: [https://dizzitech.github.io/](https://dizzitech.github.io/), русский маршрут — [/ru/](https://dizzitech.github.io/ru/).

Сборка выполняется локально, готовые файлы коммитятся в `docs/`. Собственный GitHub Actions workflow удалён. В Pages используется **Deploy from a branch → main → /docs** (`build_type: legacy`). Корень репозитория содержит README и исходники; корнем опубликованного сайта становится содержимое `docs/`, поэтому открывается лендинг `docs/index.html`.

Обновление сайта:

```powershell
npm.cmd ci
npm.cmd run build:pages
node scripts/check-pages.mjs
git status
git add docs src public scripts tests site.config.mjs package.json package-lock.json README.md TESTING.md CHANGELOG.md
git commit -m "Update DiziTech static site"
git push origin main
```

При локальных изменениях оформления сначала также выполните `npm.cmd run build` и `npm.cmd test`. `dist/` остаётся локальным предпросмотром; публикуется только `docs/`. В `docs/` входят обе HTML-страницы, CSS, JS, словари, изображения, локальные шрифты с лицензией, 404, robots, sitemap и `.nojekyll`. Production формирует canonical/hreflang/OG и разрешает индексацию; preview намеренно остаётся `noindex`.

Проверка опубликованных файлов и браузерных функций: `node scripts/check-pages.mjs --url https://dizzitech.github.io/`. Она сверяет SHA-256 всех 18 публичных файлов с локальной `docs/`, оба языка, восемь ширин, Canvas, курсор, язык, диалоги и анимации. Локальный отчёт до публикации — `reports/pages-local/result.json`; отчёт реального сайта сохраняется локально в игнорируемый `artifacts/pages-live/result.json`. Не отправляются `node_modules/`, `.npm-cache/`, `dist/`, `versions/`, `artifacts/` и тестовые контакты из `test-results/`.

## Сравнение и архивы

Оригинал **`artifacts/DiziTech-1.3.zip`** сохранён без изменений. Контрольная копия — `versions/1.3/DiziTech-1.3/`. Более ранние версии также сохранены. Архив **`artifacts/DiziTech-1.4.zip`** сохраняет базовую 1.4 до точечной коррекции чистого белого. Актуальная исправленная версия находится в `src/` и `dist/`; архивы не перезаписывались.

Наглядное сравнение: **`reports/comparison/index.html`**. Полная высота совпадает с 1.3 во всех 16 вариантах: **изменение 0 px / 0%**. Структура, отступы секций и размеры шрифтов сохранены. Сравнение выполнено при одинаковой ширине, языке, viewport 1000 px, загруженных шрифтах и reduced motion.

Для воспроизведения старого сравнения: `node scripts/compare.mjs`; цветов — `node scripts/color-audit.mjs`. Для них нужна контрольная папка 1.3. Текущая сохранность оформления и production-проверка: `node scripts/verify-preserved.mjs` — сравнение с Git-коммитом до исправления Pages и проверка `docs/`. Серверы QA временные и закрываются после работы.
